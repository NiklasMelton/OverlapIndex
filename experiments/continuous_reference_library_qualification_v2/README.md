# Continuous reference-library qualification V2

V2 is a new immutable qualification stage created after V1 failed its
predeclared endpoint gate. It preserves every V1 outcome and reruns the entire
panel with wider actionable ranges.

The known `noise_only` synthetic candidate remains in all fits and reports, but
is predeclared diagnostic-only for grid adequacy: there is no population-optimal
head scale when every head is uninformative. Likewise, k=472 is the largest
neighborhood supported by every inner training fold and is a structural, not
search, endpoint. All other material endpoint advantages remain blocking.

No OverlapIndex method or reserved backbone is evaluated.
