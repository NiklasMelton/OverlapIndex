# Real continuous-target opportunity-stratified discovery

This no-refit development diagnostic joins four immutable real-data result
sources. It asks which task/roster cells contain *rank-changing* nonlinear
head opportunity, rather than merely a nonlinear head improvement for an
individual backbone.

The admission rule is frozen before the joint analysis. It requires a
recoverable target, enough between-backbone utility spread, material nonlinear
uplift prevalence, and at least one material rank-change criterion. Recoverable
cells that fail the full rule form the LP-dominated control stratum.

All four common training-only rankers are then reported separately in the
opportunity and control strata. This is discovery evidence only: it performs no
head, embedding, or OI fit and cannot promote a method or support a confirmation
claim.

```bash
PYTHONPATH=. python -m \
  experiments.continuous_real_opportunity_stratified_discovery.run
```
