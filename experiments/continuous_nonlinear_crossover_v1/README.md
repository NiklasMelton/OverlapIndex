# Continuous nonlinear crossover V1

This frozen diagnostic asks whether a continuous ranking score changes its
winner when the higher-quality representation changes from an axis-aligned
linear signal to a signed-pair nonlinear signal.

The two scenarios use fresh rows and seeds. Each panel includes the competing
axis and signed candidates plus two weaker controls. The held-out best-head
envelope contains the calibrated screened-linear and screened-pair heads. The
ranking methods see training rows only.

The result tests a controlled capability. It cannot promote a method for real
backbone ranking.
