# Continuous reference-library qualification V3

V3 is the final bounded qualification stage before the eight-target historical
screen. It reruns the complete V2 panel, adds larger standardized RBF epsilon
values, and aligns endpoint adequacy with the best-head estimand.

Every material endpoint is recorded. It is actionable when the head attains
inner-CV R2 of at least 0.05, or when it is the intended head on a clean
synthetic control. Known null candidates, unlearnable head cells, and the
largest mathematically feasible k remain diagnostic but cannot trigger an
unbounded search toward a constant predictor.

No OverlapIndex method or reserved backbone is evaluated.
